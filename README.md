# Rekrutacyjne: Analiza rozmów i zbijania obiekcji

- Notebook: `notebooks/objections_analysis_prototype.ipynb`
- Dane wejściowe: `transcripts_combined - sample2.csv`

Szybki start (lokalnie):
1. python3 -m venv .venv && source .venv/bin/activate
2. pip install -r requirements.txt
3. jupyter notebook notebooks/objections_analysis_prototype.ipynb

Szybki start (Colab):
- Wgraj CSV i notebook do Colab lub zamontuj GDrive, dostosuj ścieżki.

Artefakty:
- Raporty: `reports/`
- Slajdy: `slides/3_slides.md`
- Narracja: `reports/narrative.md`
